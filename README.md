# RadioLink Android

پروژه متن‌باز برای بررسی امکان ارتباط صوتی محلی بین گوشی‌های اندرویدی، بدون اینترنت و سیم‌کارت.

## وضعیت فعلی

نسخه `0.1.0` فقط اسکلت اولیه اپلیکیشن و آزمایش کشف دستگاه‌های اطراف با Android Wi-Fi P2P را فراهم می‌کند. **هنوز اتصال بین دو گوشی، انتخاب میزبان، انتقال صدا یا مکالمه PTT پیاده‌سازی نشده است.**

## پیش‌نیازها

- Android Studio نسخه جدید
- JDK 17
- دو گوشی اندرویدی با Wi-Fi فعال و پشتیبانی از Wi-Fi Direct
- فعال بودن مجوزهای لازم
- برای آزمایش اولیه، هر دو گوشی باید نزدیک یکدیگر باشند

## اجرا

1. پوشه پروژه را در Android Studio باز کنید.
2. منتظر بمانید Gradle Sync کامل شود.
3. برنامه را روی هر دو گوشی نصب کنید.
4. Wi-Fi هر دو گوشی را روشن کنید.
5. مجوزهای میکروفون و دستگاه‌های نزدیک را تأیید کنید.
6. روی هر دو گوشی «جست‌وجوی گوشی‌های نزدیک» را بزنید.

## نکته درباره آفلاین بودن

برنامه برای سوکت‌های شبکه محلی مجوز `INTERNET` اندروید را اعلام می‌کند؛ این مجوز به‌تنهایی به معنی استفاده از اینترنت نیست. در نسخه عملیاتی، هیچ سرور ابری، سیم‌کارت، دیتای موبایل یا سرویس اینترنتی استفاده نخواهد شد. برای آزمون آفلاین، اینترنت و دیتای موبایل را خاموش کنید و Wi-Fi را روشن نگه دارید.

## معماری هدف

- Wi-Fi P2P: کشف و ایجاد گروه محلی
- انتخاب خودکار Group Owner توسط مذاکره Wi-Fi P2P اندروید
- سوکت محلی: انتقال داده صوتی
- AudioRecord / AudioTrack: ضبط و پخش
- Opus: فشرده‌سازی صوت در مرحله بعد
- PTT: کنترل نوبت مکالمه

## محدودیت مهم

Wi-Fi Direct برد تضمین‌شده‌ای در ساختمان بتنی ده‌طبقه ندارد. نتیجه باید با گوشی‌های واقعی و در محل پروژه اندازه‌گیری شود. این نسخه صرفاً نقطه شروع آزمایش است.
